# ConvertFrom-HtmlAppState
## SYNOPSIS
Extracts common embedded application state objects from HTML.

## SYNTAX
### Node (Default)
```powershell
ConvertFrom-HtmlAppState [-HtmlNode] <HtmlNode> [-Proxy <string[]>] [-ProxyCredential <pscredential>] [<CommonParameters>]
```

### Content
```powershell
ConvertFrom-HtmlAppState -Content <string> [-Proxy <string[]>] [-ProxyCredential <pscredential>] [<CommonParameters>]
```

### File
```powershell
ConvertFrom-HtmlAppState -Path <string> [-Proxy <string[]>] [-ProxyCredential <pscredential>] [<CommonParameters>]
```

### Url
```powershell
ConvertFrom-HtmlAppState -Url <uri> [-Proxy <string[]>] [-ProxyCredential <pscredential>] [-RetryCount <int>] [-BrowserHeaders] [-RenderWhenBlocked] [-ResumeInBrowser] [-ResumeTimeoutSeconds <int>] [-CdpEndpointUrl <string>] [-ReplayCache <string>] [<CommonParameters>]
```

## DESCRIPTION
Extracts common embedded application state objects from HTML.

## EXAMPLES

### EXAMPLE 1
```powershell
ConvertFrom-HtmlAppState -Content $html
```


### EXAMPLE 2
```powershell
ConvertFrom-Html -Content $html | Select-HtmlNode -XPath '//script[@id="__NEXT_DATA__"]' | ConvertFrom-HtmlAppState
```
