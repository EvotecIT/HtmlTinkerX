# New-HtmlBrowserCookie
## SYNOPSIS
Cmdlet that creates a new HtmlCookie instance.

## SYNTAX
### __AllParameterSets
```powershell
New-HtmlBrowserCookie [-Name] <string> [-Value] <string> [-Domain <string>] [-Path <string>] [-Url <string>] [-Expires <long>] [-HttpOnly] [-Secure] [-SameSite <SameSiteAttribute>] [<CommonParameters>]
```

## DESCRIPTION
Cmdlet that creates a new HtmlCookie instance.

## EXAMPLES

### EXAMPLE 1
```powershell
New-HtmlBrowserCookie -Path 'C:\Path'
```
