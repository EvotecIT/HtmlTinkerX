# Get-HtmlBrowserElement
## SYNOPSIS
Returns browser-observed DOM element information from an active session.

## SYNTAX
### __AllParameterSets
```powershell
Get-HtmlBrowserElement [[-Session] <HtmlBrowserSession>] [[-Selector] <string>] [-VisibleOnly] [-IncludeAttributes] [-IncludeHtml] [-Limit <int>] [-Timeout <int>] [-CancellationToken <CancellationToken>] [<CommonParameters>]
```

## DESCRIPTION
Returns browser-observed DOM element information from an active session.

## EXAMPLES

### EXAMPLE 1
```powershell
$session = Start-HtmlBrowserSession -Url https://example.org/catalog
Get-HtmlBrowserElement -Session $session -Selector '.product-card' -VisibleOnly -IncludeAttributes
```
