# Clear-HtmlBrowserCache
## SYNOPSIS
Cleans up Playwright browser downloads and cache.

## SYNTAX
### __AllParameterSets
```powershell
Clear-HtmlBrowserCache [-Force] [-SkipBrowsers] [-SkipTemp] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Cleans up Playwright browser downloads and cache.

## EXAMPLES

### EXAMPLE 1
```powershell
Clear-HtmlBrowserCache -Force
```
