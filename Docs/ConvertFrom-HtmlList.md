# ConvertFrom-HtmlList
## SYNOPSIS
Converts HTML lists into PowerShell objects by default.

## SYNTAX
### Content (Default)
```powershell
ConvertFrom-HtmlList -Content <string> [-Engine <HtmlParserEngine>] [-IncludeMetadata] [-AsString] [-TagPlaceholder <string>] [-Proxy <string[]>] [-ProxyCredential <pscredential>] [<CommonParameters>]
```

### Url
```powershell
ConvertFrom-HtmlList -Url <uri> [-Engine <HtmlParserEngine>] [-IncludeMetadata] [-AsString] [-TagPlaceholder <string>] [-Proxy <string[]>] [-ProxyCredential <pscredential>] [-RetryCount <int>] [-BrowserHeaders] [-RenderWhenBlocked] [-ResumeInBrowser] [-ResumeTimeoutSeconds <int>] [-CdpEndpointUrl <string>] [-ReplayCache <string>] [<CommonParameters>]
```

## DESCRIPTION
Converts HTML lists into PowerShell objects by default.

## EXAMPLES

### EXAMPLE 1
```powershell
ConvertFrom-HtmlList -Content $html
```
